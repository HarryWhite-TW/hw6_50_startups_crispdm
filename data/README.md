# Synthetic Dataset

Run the generator script to create the teaching dataset:

```bash
python src/generate_synthetic_startups.py
```

This creates:

```text
data/50_Startups.csv
```

This CSV is an AI-generated synthetic 50 Startups-style dataset for educational CRISP-DM workflow demonstration. It is not the original Kaggle dataset and should not be used for real business research or causal conclusions.
