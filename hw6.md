# HW6 Report: Synthetic 50 Startups CRISP-DM Startup Profit Prediction

## 1. Business Understanding

The purpose of this project is to build a regression model that predicts startup profit in an educational demonstration. The business-style question is:

> Can we predict a startup's profit using spending information and its operating state?

This project uses an AI-generated synthetic 50 Startups-style dataset for educational CRISP-DM workflow demonstration. The dataset is not used for real business research. The goal is to demonstrate the full machine learning workflow, not to claim real-world causal conclusions.

This example is useful because it lets us practice a complete machine learning workflow with a familiar startup-profit prediction problem. In this homework, the target variable is `Profit`, and the input features are startup expenses and location.

The machine learning task is supervised regression because the target value is numeric.

## 2. Data Understanding

The dataset used in this project is an AI-generated synthetic 50 Startups-style dataset. It contains 50 startup records and follows the same general column style often used in 50 Startups teaching examples.

The data is generated by `src/generate_synthetic_startups.py` and saved as:

```text
data/50_Startups.csv
```

Expected columns:

- `R&D Spend`: money spent on research and development
- `Administration`: money spent on administration
- `Marketing Spend`: money spent on marketing
- `State`: startup location category
- `Profit`: startup profit

Synthetic data generation logic:

- `R&D Spend` has the strongest predictive signal in the synthetic formula.
- `Marketing Spend` has a medium predictive signal.
- `Administration` has a smaller predictive signal.
- `State` creates a small location adjustment.
- Random noise is added to avoid perfectly linear data.
- A fixed random seed is used so the dataset is reproducible.

Since the dataset has only 50 rows, the model evaluation may be sensitive to the train/test split. Therefore, 5-fold cross-validation is included to better understand performance stability.

The Python script checks:

- Dataset shape
- Column names
- Missing values
- Basic descriptive statistics

## 3. Data Preparation

The target column is:

- `Profit`

The feature columns are:

- `R&D Spend`
- `Administration`
- `Marketing Spend`
- `State`

Data preparation steps:

1. Separate features `X` and target `y`.
2. Identify numeric and categorical columns.
3. Encode the categorical `State` column using `OneHotEncoder`.
4. Keep numeric columns unchanged.
5. Split the dataset into training and testing sets.

`OneHotEncoder` is used for `State` because the state values are categories without numeric order. `LabelEncoder` is not used because it could incorrectly imply an order between states.

## 4. Modeling

The model used in this project is:

- Linear Regression

Linear Regression is a suitable beginner-friendly baseline model for this dataset because it is easy to interpret and commonly used for numeric prediction problems.

The implementation uses a scikit-learn pipeline:

- `ColumnTransformer` handles preprocessing.
- `OneHotEncoder` transforms `State`.
- `LinearRegression` trains the prediction model.

The pipeline design keeps preprocessing and modeling together, which makes training, testing, cross-validation, and saving the model cleaner.

## 5. Evaluation

The model is evaluated using:

- R2 Score
- MAE
- RMSE
- 5-fold cross-validation R2 score

Actual model results:

- Test R2 Score: 0.9460
- Test MAE: 5578.56
- Test RMSE: 6971.82
- 5-fold CV mean R2: 0.9694
- 5-fold CV standard deviation: 0.0165

R2 Score explains how much variance in profit is explained by the model. MAE measures the average absolute prediction error. RMSE also measures prediction error, but it gives larger errors more weight.

Because the dataset is small, 5-fold cross-validation is important. It trains and validates the model on different splits of the data, which gives a better view of model stability than only one train/test split.

The script also creates a feature selection performance plot:

```text
outputs/feature_selection_performance.png
```

The plot compares model performance using different feature sets:

- `R&D Spend`
- `R&D Spend` + `Marketing Spend`
- all numeric features
- all features including one-hot encoded `State`

In this synthetic dataset, `R&D Spend` has strong predictive ability because the generated formula was designed that way. This does not mean that real-world R&D spending directly causes profit to increase.

### Feature Selection Comparison

An additional script, `src/feature_selection_comparison.py`, compares five feature selection methods on the same synthetic dataset:

- Sequential Forward Selection (SFS / Forward)
- RFE
- SelectKBest
- Lasso
- Random Forest feature importance

Before feature selection, `State` is converted with one-hot encoding and `drop_first=True`, which creates interpretable expanded features such as `State_Florida` and `State_New York`. Each method creates a complete feature ranking. Then the top 1, 2, 3, 4, and 5 features from each ranking are evaluated with the same Linear Regression model.

The output chart is saved as:

```text
outputs/feature_selection_performance_allinone.png
```

The chart shows RMSE and R2 by number of selected features, plus a top-5 ranking table for all methods. In the current synthetic dataset, feature sets that include `R&D Spend` and `Marketing Spend` early usually perform better because those variables have strong signal in the synthetic data generation formula. The best observed result from the comparison is SFS / Forward with 4 features: `R&D Spend`, `Marketing Spend`, `State_New York`, and `Administration`.

This comparison is useful because it shows that different feature selection methods can produce different rankings. However, the result should not be treated as evidence of real-world causality. It only explains model behavior on this reproducible synthetic teaching dataset.

This saved file includes preprocessing and the trained Linear Regression model. It can be loaded later with `joblib` to make predictions on new startup data that follows the same column format.

This project demonstrates a complete CRISP-DM machine learning workflow for a regression problem.
